A one-line horror generator: `main.py` writes one fixed, deterministic horror sentence (101 characters) to `/output/entry.txt`, with a built-in guard that refuses to write unless the line is exactly one sentence and 1–200 characters.

## Run it

```sh
python3 main.py
```
